How old is the code in CiviCRM?

Each line of CiviCRM core, dated by the year it was last changed.

Age mix of the codebase over time

The code as it stood on the first of each month and today, split by the year each line was last changed, as a share of all lines. Old layers shrink as code is rewritten or removed.

Size of the codebase by age

The same layers in lines of code. The upper edge is the size of the codebase, so growth and removals show directly. A layer can only shrink once its years are over.

How long code survives

Of the lines that reached master in a given year, the share still unchanged after n years. The half-life is the time until half of them have been changed or deleted.
